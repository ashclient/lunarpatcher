Frame rate

Roblox now has its own supported maximum frame-rate control (up to 240 FPS on Windows). This selector is a reminder for the target you want to use; it does not bypass the client’s cap or write unsupported FastFlags.

In Roblox: Escape → Settings → Maximum Frame Rate → choose the value above.

Graphics and performance

Roblox graphics quality and fullscreen behavior are controlled inside Roblox. These shortcuts open the player and explain where to configure them without fragile client modifications.

Graphics qualityEscape → Settings → Graphics Mode: Manual, then choose quality.
Performance statsPress Shift + F5 inside a game to view live performance.
FullscreenUse Roblox's fullscreen setting; exclusive fullscreen may be platform-dependent.
Unsupported FastFlagsNot written, injected, or advertised as an FPS unlocker.

How updates work

New versions are checked automatically at startup and while LunarPatcher is open. The installer is downloaded to the application update cache—not your Downloads folder.

No manual installer needed

When an update is ready, restart from this screen to install it quietly. Your Lunar Client backups and selected appearance stay in place.

LunarPatcher updates are separate from Lunar Client launcher updates.
